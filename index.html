📌 Información importante:

Este proyecto es una aplicación Laravel (PHP) que no puede ejecutarse en GitHub Pages porque requiere:

  • ✓ Un servidor PHP (PHP 8.2+)
  • ✓ Una base de datos (SQLite, MySQL, etc.)
  • ✓ Composer para las dependencias PHP
  • ✓ Node.js y NPM para los assets

🚀 ¿Cómo desplegar correctamente?

Necesitas usar un hosting que soporte PHP. Algunas opciones gratuitas:

  • Railway (railway.app) - Tiene plan gratuito
  • Render (render.com) - Plan gratuito disponible
  • Laravel Cloud (cloud.laravel.com) - Nuevo servicio oficial
